# Occult Weakness

Plugin Dalamud pour Final Fantasy XIV qui mémorise la faiblesse élémentaire des monstres d'Occult Crescent et affiche l'icône correspondante à gauche de la target nameplate.

## Fonctionnalités

- Association par nom de monstre, sans dépendre des IDs instables.
- Affichage fixe à gauche de la target nameplate.
- Configuration via `/ocweak`.
